## 關於我

我是 **元智大學（YZU）資訊工程學系**應屆畢業生，研究方向橫跨**電腦視覺、視覺語言模型、資安、量化研究與機器學習**。

我的研究圍繞一個問題：**如何打造能理解複雜訊號、可靠推理，並在真實世界的不確定性下維持實用性的學習系統？** 我喜歡把研究構想轉化成可運作的原型，從多模態推理實驗、模型評估流程，到決策支援工具與互動式系統。

> 目前專注於電腦視覺、多模態模型、AI 安全與量化機器學習，並持續把研究想法落地成可驗證、可互動的系統。
