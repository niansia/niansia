## 关于我

我今年刚从**元智大学（YZU）计算机科学专业**毕业，主要关注 **AI 安全、计算机视觉与视觉语言模型**的交叉领域，尤其是可靠的多模态推理与模型评估。

我喜欢把研究问题转化为可复现的实验与可运行的系统，从证据导向的研究工具、模型评估流程，到交互式软件。目前部分研究仍在开发或评审阶段，因此保持非公开；代码、结果与可复现成果将在合适的时间发布。
