## 关于我

我今年刚从**元智大学（YZU）计算机科学专业**毕业，主要关注 **AI 安全、计算机视觉与视觉语言模型**的交叉领域，尤其是可靠的多模态推理与模型评估。

我把研究问题转化为可复现的实验与可运行的系统。目前的代表作是 [Merriv](https://github.com/niansia/Merriv)：它将模型工件、配对评估、统计策略与来源信息绑定为可供独立验证的发布证据。
