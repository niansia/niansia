## 关于我

我是**元智大学（YZU）信息工程专业**应届毕业生，研究方向涵盖**计算机视觉、视觉语言模型、网络安全、量化研究与机器学习**。

我的研究围绕一个问题：**如何构建能够理解复杂信号、可靠推理，并在真实世界的不确定性下保持实用性的学习系统？** 我喜欢把研究构想转化为可运行的原型，从多模态推理实验、模型评估流程，到决策支持工具与交互式系统。

> 目前专注于计算机视觉、多模态模型、AI 安全与量化机器学习，并持续把研究想法落地为可验证、可交互的系统。
